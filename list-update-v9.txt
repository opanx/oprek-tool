### 1. Root IL2CPP Dumper (Priority #1)

Create a complete **IL2CPP Dumper** that works with **root access**.

#### Core Idea
- Requires root (Magisk / KernelSU / SuperSU etc.)
- Can dump from:
  - Running process (attach to game process)
  - Or from libil2cpp.so + global-metadata.dat on disk
- Generate clean header files ready for use

#### Output (must support multiple formats):
- `il2cpp.h`
- `game.h`
- `main.h`
- Optionally `script.json` / structured dump
- Frida-ready stubs (bonus)

#### What to dump:
- Classes
- Methods + full signatures
- Fields + types
- Type definitions
- Image / assembly info
- As much metadata as possible

#### Technical Requirements:
- Root detection + proper su handling
- Ability to read process memory (maps, mem)
- Parse IL2CPP structures from memory or from files
- Support both ARM32 and ARM64
- Memory efficient (streaming / chunked reading)
- Progress bar + cancel button
- Save to `/sdcard/oprek-tool/il2cpp/` or user-chosen location
- Clear error messages when root is not available or process not found

#### UI:
- New dedicated screen: "IL2CPP Dumper (Root)"
- Options:
  - Dump from running process (package name / PID selector)
  - Dump from files (libil2cpp.so + global-metadata.dat)
  - Output format selector (il2cpp.h / game.h / main.h)
  - Filter options (public only, include methods, include fields, etc.)
- Result viewer + export/share/copy

Make it as accurate and usable as possible for real Unity games.

### 2. DEX Dumper

Also create a **DEX Dumper** feature.

#### Features:
- Dump DEX from:
  - APK
  - Running process (root preferred)

- Support multi-DEX

- Optional: convert dumped DEX to Java/Smali preview
- Handle packed / encrypted DEX as best as possible (at least detect and extract raw)

#### UI:
- New screen or integrated into existing APK/Android tools
- Clear root vs non-root modes
